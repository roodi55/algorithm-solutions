# ✦ Holo Invitation — 인터랙티브 홀로그램 초대장

스마트폰으로 링크에 접속한 뒤 투명 반사판(45° 한 장 또는 4면 역피라미드)을 올리면,
금빛 왁스 씰과 초대 문구가 공중에 떠오르는 연말 파티 초대장 웹 앱입니다.
설치나 빌드가 필요 없고, `index.html` 파일 하나로 동작합니다.

## 폴더 구조

```
hologram-invitation/
├── index.html   ← 앱 전체 (HTML + CSS + Canvas JS, 외부 로컬 파일 의존 없음)
└── README.md    ← 이 문서
```

`index.html` 내부 구성:

| 영역 | 내용 |
| --- | --- |
| `#screen-setup` | Step 1. 반사판 타입 선택, 배치 가이드 SVG, 밝기 안내 |
| `#screen-holo` | Step 2. 순수 #000000 캔버스 반사 연출, 우측 상단 반전·조정·상세 버튼 |
| `#screen-detail` | Step 3. 네이비 + 금박 카드, 일시·지도·드레스코드·호스트 메시지·RSVP |
| `#modal-result` | RSVP 결과 확인 (문자·공유·복사) |
| `#modal-editor` | 호스트 편집기: 정보를 입력하면 게스트별 공유 링크 생성 |
| `UnitRenderer()` | 엠블럼·타이틀·게스트·날짜를 정사각 유닛 하나로 렌더링하는 캔버스 엔진 |

## 광학 시인성 설계 포인트

1. **순수 #000000 배경**: 반사 화면은 매 프레임 `#000000`으로 채우고 회색이나 그라데이션 배경을 쓰지 않습니다. 검정 픽셀은 반사판에 비치지 않아서 화면 테두리 빛 번짐 없이 상만 떠 보입니다.
2. **유닛 렌더 + 변환 복제**: 그래픽을 정사각 유닛 하나에 그린 뒤 1면 모드에서는 한 번, 피라미드 모드에서는 중앙 기준 0°·90°·180°·270°로 4번 찍습니다. 그래서 네 면의 크기와 애니메이션 위상이 완전히 같습니다.
3. **반전 보정**: ↕(상하) 기본값은 **켜짐**입니다. 휴대폰 하단이 보는 사람을 향하고 판 윗부분이 사람 쪽으로 기운 배치에서는 반사상이 상하로 뒤집히기 때문입니다. 배치가 다르면 ↔/↕로 즉시 보정하고, 설정은 모드별로 기기에 저장됩니다. 반전은 유닛 단위로 적용되므로 피라미드 네 면이 각자 올바르게 보정됩니다.
4. **이중상(고스트) 대응 타이포**: 얇은 명조 대신 Cinzel 900과 Noto Serif KR 900을 쓰고, 자간을 넓혔습니다(타이틀 0.06em, DEAR 0.45em). 글자는 순백 `#FFFFFF`에 `#FFD700` 글로우를 이중 패스로 입혔습니다. 반사판 앞·뒷면 이중상이 겹쳐도 획이 뭉개지지 않습니다.
5. **정보 분리 (하이브리드 UX)**: 반사 모드에는 엠블럼, 파티명, 게스트명, 날짜·카운트다운만 크게 띄웁니다. 주소, 지도, 드레스코드, RSVP는 상세 화면에서 읽고 터치합니다.
6. **반사 영역 밖 UI**: 컨트롤은 우측 상단 모서리에 어두운 회색으로 작게 두고, 4초 뒤 자동으로 숨깁니다. 화면을 탭하면 다시 나타납니다. 피라미드 정렬 사각형도 메뉴가 보일 때만 그립니다.
7. **기타**: 화면 꺼짐 방지(Wake Lock), 전체 화면 요청(지원 기기), 가산 합성(`lighter`)으로 파티클 발광을 표현하고, 정적 레이어를 캐싱해서 모바일 성능을 확보했습니다.

## 사용법

| URL | 동작 |
| --- | --- |
| `index.html` | 기본 초대장 |
| `index.html?guest=홍길동` | 게스트 이름 개인화 (`홍길동 님`) |
| `index.html?edit` 또는 `index.html#edit` | 호스트 편집기 열기 (세팅 화면 하단 링크로도 열 수 있음) |

지원 쿼리 파라미터는 `title`, `sub`, `mono`, `date`(예: `2026-12-31T19:00`), `venue`, `addr`, `map`, `dress`, `host`, `msg`, `contact`, `guest`입니다.
편집기에서 정보를 입력하고 게스트 이름을 한 줄에 한 명씩 적으면 게스트별 링크를 만들어 줍니다.

> RSVP는 서버 없이 동작합니다. 응답은 게스트 기기에 저장되고, 게스트가 결과 모달의 **문자, 공유, 복사** 버튼으로 호스트에게 직접 보냅니다. 응답을 한곳에 모으려면 Google Forms나 Apps Script 같은 엔드포인트를 따로 연결해야 합니다.

## 경로 이동 / 배포 시 체크리스트

- **폴더를 통째로 옮기면 됩니다.** 로컬 이미지, CSS, JS 참조나 절대 경로가 없습니다. 외부 의존은 CDN 두 개뿐입니다(Google Fonts, Tailwind 브라우저 빌드 `@tailwindcss/browser@4.1.11`).
- **공유 링크는 현재 주소 기준으로 생성됩니다** (`location.href`에서 쿼리와 해시를 뺀 값). 다른 폴더, 도메인, 하위 경로(예: `https://user.github.io/repo/hologram-invitation/`)로 옮겨도 코드를 고칠 필요가 없습니다. 단, **옮기기 전에 만든 링크는 예전 주소를 가리키므로 옮긴 뒤 다시 생성하세요.**
- **`/edit` 경로 라우팅을 쓰지 않습니다.** 정적 호스팅에서 404가 나지 않도록 편집기는 `?edit` / `#edit`로 엽니다. 서버 rewrite 설정이 필요 없습니다.
- **파일명을 바꿔도 됩니다** (`index.html` → `invite.html`). 링크가 현재 파일명을 그대로 사용합니다.
- **`file://`로 열면** 로컬 미리보기는 되지만, 그 주소로 만든 링크는 다른 사람이 열 수 없습니다(편집기에 경고 표시). 공유하려면 GitHub Pages, Netlify, Vercel 같은 HTTPS 호스팅에 올리세요. Wake Lock과 클립보드도 HTTPS에서만 동작합니다.
- 이 폴더는 Java 소스(`src/`) 밖에 있어서 Eclipse 빌드에 영향을 주지 않습니다. 다른 저장소로 옮길 때도 이 폴더만 복사하면 됩니다.
- 오프라인이라 Tailwind CDN이 로드되지 않아도 핵심 레이아웃(화면 전환, 반사 화면 버튼, 폼)은 자체 CSS로 유지됩니다. 장식 스타일만 단순해집니다.

## 로컬 실행

```bash
cd hologram-invitation && python3 -m http.server 8000
```

같은 Wi-Fi의 휴대폰에서 `http://<PC-IP>:8000/?guest=홍길동` 으로 접속합니다.
